# Trip Cost Share v5.6.1

## สิ่งที่ปรับ

- นำหน้า **ข้อมูลที่พัก** ออกจากหน้าใช้งานหลัก (Index)
- ย้ายตัวเลือก **คืนที่เข้าพัก** กลับไปอยู่ในหน้า **บันทึกผู้ร่วมกิจกรรม** เหมือนแนวทางก่อนทำเป็น Index
- ตอนเพิ่มผู้ร่วมกิจกรรม สามารถเลือกได้ในหน้าเดียว:
  - ชื่อ
  - วันที่เข้าร่วม
  - คืนที่เข้าพัก
  - สถานะดื่มแอลกอฮอล์
- หน้าหลักเหลือเมนู:
  - Dashboard
  - ผู้ร่วมกิจกรรม
  - บันทึกค่าใช้จ่าย
  - Admin

## สิ่งที่ไม่เปลี่ยน

- ไม่เปลี่ยนโครงสร้างฐานข้อมูล
- ไม่เปลี่ยน API
- ไม่กระทบข้อมูลเดิมใน Google Sheet
- ค่าใช้จ่ายแบบ "ผู้ที่พักในคืนที่เลือก" ยังทำงานเหมือนเดิม เพราะยังใช้ `lodgingNights` เหมือนเดิม

## วิธีอัปเดต

หากต้องการอัปเดตอย่างปลอดภัย ให้อัปโหลดไฟล์ต่อไปนี้ขึ้น GitHub แทนของเดิม:

- `index.html`
- `app.js`
- `navigation.js`

ไม่ต้องเปลี่ยน:

- `config.js`
- `admin.html`
- `admin.js`
- `styles.css`
- `apps-script/Code.gs`

จากนั้นกด `Ctrl + F5` เพื่อรีเฟรชแบบล้างแคช
