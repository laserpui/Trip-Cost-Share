# Trip Cost Share v5.5 Stable

เวอร์ชันนี้แก้ 2 ประเด็นหลัก:

1. ปรับหน้า **ข้อมูลที่พัก** เป็นตารางกำหนดคืนพักทั้งกลุ่มและบันทึกพร้อมกัน
2. แก้ปัญหา **บันทึกกิจกรรม / ช่วงวันที่ในหน้า Admin** ที่ Google Sheet อาจแปลงค่า YYYY-MM-DD เป็น Date object อัตโนมัติ

## 1) หน้า “ข้อมูลที่พัก” แบบใหม่

- แถว = ผู้ร่วมกิจกรรม
- คอลัมน์ = คืนที่พัก
- เลือก/ยกเลิกได้รายคน รายคืน
- ปุ่ม “เลือกทั้งคืน” บนหัวคอลัมน์
- ปุ่ม “เลือกทุกช่อง” และ “ล้างทั้งหมด”
- บันทึกข้อมูลทุกคนด้วยปุ่มเดียว
- แสดงสรุปจำนวนคนค้างคืนและจำนวน “คน-คืน”
- ถ้ากิจกรรมมีวันเดียว ระบบจะแจ้งว่าไม่มีคืนพัก

ระบบยังเก็บข้อมูลใน `Participants.lodgingNights` เหมือนเดิม จึง **ไม่เปลี่ยนโครงสร้างฐานข้อมูล**

## 2) แก้ปัญหา “บันทึกกิจกรรมไม่ได้”

สาเหตุสำคัญที่พบคือ Google Sheet สามารถตีความข้อความ เช่น `2026-08-08` เป็นชนิด Date อัตโนมัติ เมื่อ Apps Script อ่านกลับ โค้ดเดิมอาจได้ข้อความ Date แบบยาวแทน `YYYY-MM-DD` ทำให้หน้า Admin แสดงวันที่ว่างหรือดูเหมือนไม่ได้บันทึก

v5.5 แก้โดย:

- อ่านค่า Date เดิมใน Settings แล้วแปลงกลับเป็น `YYYY-MM-DD`
- ใช้ timezone ของ Spreadsheet ก่อน และ fallback เป็น `Asia/Bangkok`
- บังคับเซลล์ Settings ที่บันทึกใหม่ให้เป็น Text ก่อนเขียนวันที่
- หน้า Admin ตรวจผลตอบกลับหลังบันทึกว่าชื่อกิจกรรม วันเริ่ม วันสิ้นสุด และสถานะตรงกับค่าที่กรอกหรือไม่
- แสดงข้อความสำเร็จ/ข้อผิดพลาดภายในหน้าตั้งค่ากิจกรรม
- รองรับ action ทั้ง `adminUpdateSettings` และ `adminSaveSettings` เพื่อเพิ่มความเข้ากันได้

## 3) API ใหม่สำหรับที่พัก

เพิ่ม action:

`updateParticipantsLodgingBatch`

ใช้บันทึกคืนพักของผู้ร่วมกิจกรรมหลายคนพร้อมกัน ลดจำนวน request และลดโอกาสข้อมูลบันทึกไม่ครบ

## อัปเกรดจาก v5.4

### GitHub Pages

อัปโหลดแทนไฟล์เดิม:

- `index.html`
- `app.js`
- `styles.css`
- `admin.html`
- `admin.js`

`navigation.js` ไม่ได้เปลี่ยนสาระสำคัญ แต่สามารถใช้ไฟล์จากชุด v5.5 ได้

**อย่าเขียนทับ `config.js` ของเว็บที่ใช้งานจริง** เพราะไฟล์นั้นมี Google Apps Script Web App URL ของคุณ

### Google Apps Script

1. นำ `apps-script/Code.gs` v5.5 ไปแทนของเดิม
2. กด Save
3. เลือก **Deploy > Manage deployments**
4. กด Edit
5. เลือก **New version**
6. กด Deploy
7. เปิดหน้าเว็บและกด `Ctrl + F5`

ไม่ต้องรัน migration และไม่ต้องลบชีตเดิม

## ถ้าหน้า Admin ยังบันทึกกิจกรรมไม่ได้

หลังอัปเดต v5.5 ให้ดูข้อความใต้ปุ่ม **บันทึกกิจกรรม** โดยตรง ระบบจะแจ้งข้อผิดพลาดจริงจาก API แทนการเงียบหรือดูเหมือนปุ่มค้าง

หากข้อความแจ้งว่า Deployment ไม่ตรงเวอร์ชัน ให้ตรวจว่า Apps Script ถูก Deploy เป็น **New version** แล้ว ไม่ใช่แค่กด Save ใน editor
