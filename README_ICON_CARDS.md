# Trip Cost Share v5.2.2 — Calendar & Bed Icon Cards

แพตช์ UI นี้เพิ่ม:

- ไอคอนปฏิทินสำหรับ `วันที่เข้าร่วม`
- ไอคอนเตียงสำหรับ `คืนที่เข้าพัก`
- ปุ่มเลือกทรงกลม พร้อม gradient และ micro-interaction
- สีแยกระหว่างวันเข้าร่วมและคืนที่พัก
- รองรับทั้งหน้าหลักและหน้าหลังบ้าน
- รองรับ Desktop, Tablet และ Mobile

## ขอบเขตการแก้ไข

แก้เฉพาะ `styles.css`

ไม่มีการแก้ไข:

- app.js
- admin.js
- config.js
- Google Apps Script
- API
- Google Sheet
- สูตรคำนวณ

## วิธีติดตั้ง

1. แตกไฟล์ ZIP
2. อัปโหลด `styles.css` ไปแทนไฟล์เดิมใน GitHub
3. รอ GitHub Pages อัปเดต
4. เปิดหน้าเว็บแล้วกด `Ctrl + F5`
