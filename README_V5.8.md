# Trip Cost Share v5.8 — Expense Save Fix

เวอร์ชันนี้แก้ปัญหาหลัก 2 เรื่อง:

1. ลดการกรอกยอดซ้ำในหน้าบันทึกค่าใช้จ่าย
2. แก้บั๊กที่ทำให้บันทึกค่าใช้จ่ายไม่ได้

## UX ใหม่ของยอดใบเสร็จ

ถ้ามีผู้สำรองจ่ายเพียง 1 คน และมีรายการย่อยเพียง 1 รายการ:

- กรอก `ยอดรวมใบเสร็จ` เพียงครั้งเดียว
- ระบบใช้ยอดนี้เป็นยอดของผู้สำรองจ่ายอัตโนมัติ
- ระบบใช้ยอดนี้เป็นยอดของรายการย่อยอัตโนมัติ

ถ้ามีผู้จ่ายหลายคน:

- กด `มีผู้จ่ายหลายคน`
- ระบบจะแสดงช่องจำนวนเงินของแต่ละคนให้แบ่งยอดเอง

ถ้ามีหลายรายการย่อย:

- กด `เพิ่มรายการย่อย`
- ระบบจะปลดล็อกช่องจำนวนเงินของแต่ละรายการให้แบ่งยอดเอง

## บั๊กที่แก้

Apps Script เดิมเตรียมรายการย่อยในรูปแบบ:

```text
{ row: {...}, shares: {...} }
```

แต่ตอนรวมยอดกลับอ่านจาก `line.amount` แทน `line.row.amount`
จึงทำให้เกิดค่า NaN และการบันทึกใบเสร็จล้มเหลว

v5.8 แก้จุดนี้ทั้ง:

- การเพิ่มค่าใช้จ่ายจากหน้าเว็บ
- การแก้ไขใบเสร็จจากหน้า Admin

## Performance

สำหรับใบเสร็จใหม่ v5.8 จะ:

- ตรวจสอบข้อมูลก่อนขอ Lock
- อัปโหลดรูปก่อน Lock
- Lock เฉพาะช่วงเขียนข้อมูลจริง
- Append Receipts / ExpenseLines / ExpenseShares แบบ Batch
- ไม่อ่านฐานข้อมูลทั้งหมดกลับมาหลังบันทึก
- Retry อัตโนมัติเมื่อเจอ BUSY

## วิธีอัปเดต

อัปโหลดขึ้น GitHub แทนไฟล์เดิม:

- `index.html`
- `app.js`
- `styles.css`
- `navigation.js`

เก็บ `config.js` เดิมไว้

จากนั้นนำ:

- `apps-script/Code.gs`

ไปแทนใน Google Apps Script และ Deploy เวอร์ชันใหม่ผ่าน:

`Deploy > Manage deployments > Edit > New version > Deploy`

ไม่ต้องสร้าง New deployment และไม่ต้องเปลี่ยน URL ใน `config.js`

หลัง Deploy สามารถรันหนึ่งครั้ง:

1. `clearPerformanceCache()`
2. `warmCache()`

แล้วกลับหน้าเว็บกด `Ctrl + F5`
