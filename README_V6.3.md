# Trip Cost Share v6.3 — Dynamic Share Cards

อัปเดตเฉพาะระบบสร้างภาพแชร์ ไม่มีการเปลี่ยน Google Sheet / API / Apps Script

## 1) แชร์สรุปค่าใช้จ่ายทริป

ปุ่ม “แชร์เป็นรูป” ในหน้า Dashboard จะสร้าง Share Card ใหม่แบบ Dynamic โดยดึงข้อมูลจริง ได้แก่:

- ชื่อกิจกรรมและช่วงวันที่
- จำนวนผู้ร่วมกิจกรรม
- ค่าใช้จ่ายรวม
- ค่าเครื่องดื่มแอลกอฮอล์
- ค่าที่พัก
- ยอดรายบุคคล: ออกก่อน / รับคืน / ต้องจ่าย
- คำแนะนำการโอน
- หมายเหตุเรื่องที่พักและแอลกอฮอล์

## 2) แชร์รายการค่าใช้จ่าย

ปุ่ม “แชร์เป็นรูป” ในหน้า “รายการค่าใช้จ่าย” จะสร้างภาพอีกแบบ โดยแสดง:

- ชื่อกิจกรรมและช่วงวันที่
- ยอดรวม / จำนวนใบเสร็จ / แอลกอฮอล์ / ที่พัก
- สรุปยอดตามหมวด
- รายการใบเสร็จเรียงตามวันที่
- ร้านค้า / ผู้ให้บริการ
- ผู้สำรองจ่าย
- รายการย่อยแบบสั้น
- ยอดของแต่ละใบเสร็จ

## วิธีอัปเดต

อัปโหลดขึ้น GitHub แทนไฟล์เดิมเพียง 2 ไฟล์:

- `app.js`
- `styles.css`

ไม่ต้องเปลี่ยน:

- `config.js`
- `index.html`
- `admin.html`
- `admin.js`
- `navigation.js`
- `apps-script/Code.gs`

ไม่ต้อง Deploy Google Apps Script ใหม่

หลังอัปโหลดให้กด `Ctrl + F5`
