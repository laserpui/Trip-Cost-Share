# Trip Cost Share v5.4 Stable

เวอร์ชันนี้เป็นการแก้โครงสร้างหน้าเว็บหลังจาก v5.3.x โดยเน้นความเสถียรและแยกแต่ละหน้าการทำงานออกจากกันอย่างชัดเจน

## สิ่งที่แก้สำคัญ

### 1. แยกหน้า Index เป็น 4 โมดูลอิสระ

- Dashboard
- ผู้ร่วมกิจกรรม
- ค่าใช้จ่าย
- ข้อมูลที่พัก

แต่ละโมดูลมี Form ของตัวเอง ไม่มี Form คร่อมหลายหน้าอีกต่อไป

### 2. หน้าข้อมูลที่พักทำงานแบบอิสระ

ลำดับใช้งานใหม่:

1. เพิ่มผู้ร่วมกิจกรรมในหน้าผู้ร่วมกิจกรรม
2. เปิดหน้าข้อมูลที่พัก
3. เลือกรายชื่อที่บันทึกไว้แล้ว
4. เลือกคืนที่เข้าพักจริง
5. กดบันทึก

จึงสามารถแก้คืนที่พักภายหลังได้ โดยไม่ต้องสร้างรายชื่อใหม่

### 3. ยกเลิกระบบบันทึกการชำระเงินระหว่างสมาชิก

v5.4 ไม่อ่าน ไม่เขียน และไม่คำนวณจากข้อมูลการโอนเงินเดิมอีกต่อไป

Dashboard คำนวณจากข้อมูลหลักเพียงสองส่วน:

- ยอดที่บุคคลนั้นต้องรับผิดชอบจาก `ExpenseShares`
- ยอดที่บุคคลนั้นสำรองจ่ายจาก `Receipts`

ยอดสุทธิ = สำรองจ่าย - ยอดรับผิดชอบ

ระบบยังสามารถแสดง “คำแนะนำการโอนเพื่อปิดยอด” จากยอดสุทธิ แต่ไม่มีการบันทึกประวัติการโอน

> เพื่อป้องกันข้อมูลสูญหาย ชีต `Settlements` เดิมจะไม่ถูกลบ แต่ v5.4 จะไม่ใช้งานชีตนี้อีก

### 4. ปรับ API สำหรับหน้าที่พัก

เพิ่ม Action:

```text
updateParticipantLodging
```

Action นี้แก้เฉพาะ `lodgingNights` ของผู้ร่วมกิจกรรม และไม่เปลี่ยนชื่อ วันที่เข้าร่วม หรือสถานะอื่น

### 5. ปรับระบบปิดยอด

การตรวจสอบก่อนปิดยอดจะตรวจ:

- ยอดผู้สำรองจ่ายตรงกับใบเสร็จ
- ยอดรายการย่อยตรงกับใบเสร็จ
- ทุกรายการมี ExpenseShares
- ExpenseShares รวมตรงกับยอดรายการ
- ผู้จ่ายและผู้รับผิดชอบยังมีรายชื่ออยู่

ข้อมูลการโอนเงินเก่าจะไม่ถูกนำมาตรวจอีก

# วิธีอัปเดตจาก v5.3.x

## สำคัญ: เก็บ `config.js` เดิมไว้

ไฟล์ `config.js` ของคุณมี Google Apps Script Web App URL จริง จึงไม่ควรนำไฟล์ placeholder จากแพ็กเกจใหม่ไปเขียนทับ

ให้อัปโหลดขึ้น GitHub แทนไฟล์เดิม:

```text
index.html
admin.html
styles.css
app.js
admin.js
navigation.js
```

เก็บไฟล์เดิมของคุณ:

```text
config.js
```

## Google Apps Script

นำไฟล์:

```text
apps-script/Code.gs
```

ไปแทน Code.gs เดิม แล้วทำดังนี้:

1. Save
2. Deploy > Manage deployments
3. Edit deployment
4. เลือก New version
5. Deploy

ไม่ต้องรัน `migrateV4Data()` ซ้ำ

ไม่ต้องลบชีตใด ๆ

หลังอัปเดต GitHub ให้กด `Ctrl + F5`

# ไฟล์ที่ตรวจสอบใน v5.4

- `app.js` ผ่าน JavaScript syntax check
- `admin.js` ผ่าน JavaScript syntax check
- `navigation.js` ผ่าน JavaScript syntax check
- `Code.gs` ผ่าน JavaScript syntax check
- ID ที่ JavaScript เรียกใช้มีอยู่ใน HTML ครบ
- ไม่มี ID ซ้ำในหน้า Index และ Admin
- ไม่มี Form ซ้อน Form
- ไม่มีโค้ด Action สำหรับระบบการชำระเงินเดิมใน Frontend/Admin/API
