# Trip Cost Share v5.3.1 — ย้ายบันทึกการชำระคืน

เวอร์ชันนี้ปรับเฉพาะ UI/Navigation ของหน้า Index

## เปลี่ยนแปลง

- ย้ายส่วน “บันทึกการชำระคืน” จากหน้าบันทึกค่าใช้จ่าย
- นำไปแสดงในหน้า “บันทึกข้อมูลที่พัก”
- เปลี่ยนชื่อเมนูเป็น “ที่พักและชำระคืน” เพื่อสื่อความหมายชัดเจนขึ้น
- ปรับข้อความหัวหน้าบันทึกค่าใช้จ่าย ไม่กล่าวถึงการชำระคืนแล้ว
- รักษา ID ของฟอร์มและตารางเดิมทั้งหมด จึงใช้ app.js และ API เดิมได้

## ไม่ได้เปลี่ยน

- สูตรคำนวณ
- โครงสร้าง Google Sheet
- Google Apps Script API
- app.js / admin.js / config.js / Code.gs
- ข้อมูลเดิมของผู้ใช้

## วิธีอัปเดตแบบ UI-only

อัปโหลดไฟล์ต่อไปนี้แทนไฟล์เดิม:

- index.html
- navigation.js
- styles.css

จากนั้นกด Ctrl + F5
